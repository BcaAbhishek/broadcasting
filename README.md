# 🎵 Broadcasting Radio

A real-time live music broadcasting web application that allows multiple listeners to tune in and enjoy a synchronized music experience.

The application uses the YouTube Data API to fetch playlist information, the YouTube IFrame API for playback, and WebSockets to keep listeners synchronized with the current broadcast.
